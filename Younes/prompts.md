### **Prompt 10**

	A partir de el texto que aparece a continuación dime si esta bien usada la sintaxis markdown, el texto es el siguiente: ...

#### **Respuesta obtenida de GPT 3.5 Turbo**
	
	La sintaxis markdown utilizada en el texto es correcta. Se han utilizado los encabezados, negritas, listas y separaciones de párrafos de manera 	adecuada. No se 	observan errores en la estructura del texto.

#### **Respuesta obtenida de OpenCode BigPickle**

	La sintaxis markdown está mayormente bien usada, pero hay algunos detalles a corregir:

	Bien usado:

	Títulos # ## ### #### correctos
	Negritas **...** correctas
	Listas con -
	Problemas a corregir:

	Faltan líneas en blanco antes de títulos #### — el bloque anterior (texto en tabulación) no está separado por una línea vacía, lo que puede 	confundir el renderizado. Ejemplo:
	Escribe Hola Mundo
	#### **Respuesta obtenida...**  <- falta línea en blanco antes
	Uso de tabulaciones para indentar — los bloques como respuestas usan tabulaciones al inicio de línea, lo cual no es una sintaxis markdown 	estándar. Los navegadores markdown no reconocen la tabulación como formato; simplemente se muestran como texto normal (con sangría según el 	intérprete). Deberían usarse bloques de código (con ``` al inicio y final) o citas (>).
	La tabla del Prompt 8 — en la respuesta de OpenCode BigPickle se usa una tabla, pero el separador de cabecera marcaría que la primera fila es 	cabecera. Faltan los delimitadores |---| para que se renderice como tabla real:
	| Año | Modelo |
	|-----|--------|
	| 1997 | ... |
	En resumen: la estructura de encabezados y énfasis es correcta, pero la indentación con tabulaciones no es markdown válido y deberías reemplazarla 	por bloques de código o citas.
